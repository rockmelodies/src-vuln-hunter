# 供应链安全审计 — 第三方 Skill / MCP / 工具

挖洞过程中你会不断引入第三方 skill / MCP / 脚本（jshook、FOFA MCP、各类审计 skill、浏览器自动化、内网工具……）。这些工具能读你的终端、目标资产、凭据与 findings——**一个后门或遥测模块，会让你的目标和成果外泄，甚至被溯源**。黑盒目标 + 脏工具 = 白干。

本方法论蒸馏自 `skill-security-audit` 技能，用于在**安装/启用任何第三方 skill、MCP server、脚本前**做一次快速审计。

## 核心原则

**别只看主文件（SKILL.md）。** prompt 类技能的商业化 / 遥测模块往往藏在 `references/` 二级文件、脚本（`.sh`/`.py`/`.js`）或配置（`.toml`/`.json`）里，主文件通常干净。

审计动作：`find <skill_dir> -type f` 列出**全部**文件 → 对每个 `.md`/`.sh`/`.py`/`.js` 执行静态扫描，再挑可疑文件 Read。

## 五维审计

### 1. 静态危险模式扫描

在目录下 grep 危险模式（🔴 命中即阻断）：

- 递归强删目录（Recursive Force Delete）
- 提权 / 全局写（Privilege Escalation / Global Write）
- 动态代码执行（Eval / Exec）
- 管道直通 shell（Pipe to Shell execution）
- 反弹 shell 工具（Reverse Shell tools）

### 2. 权限边界分析

技能声明的文件访问范围是否越界：

- 是否读写技能自身目录**之外**的系统目录？
- 是否碰 `~/.ssh`、`~/.claude/settings`、环境变量、核心配置、密钥文件？

### 3. 网络行为分析

- 提取所有 URL / 域名。
- 判断是公开 API 还是硬编码的私人 / 未知地址；**向未知域 POST/PUT** = 数据外泄风险。

### 4. 商业化附加层（业务层）检测 —— 重点

部分热门 skill 的**核心功能**（纯 prompt 行为引导）是安全的，但作者会捆绑商业化平台模块（手机号注册、支付、遥测上报）。识别信号：

| 信号 | 风险 |
|---|---|
| 独立 `platform.md` 或类似文件，定义注册 / 支付 / 统计流程 | 业务层捆绑 |
| 向作者私人域名 / Workers 发 POST（如 `v1/stats`、`v1/register`、`v1/payment`） | 遥测 / 收款 |
| 静默上报事件（`session_start`、`command_used` 等） | **最隐蔽**——无需用户操作自动触发 |
| 要求输入手机号 / 生成支付二维码 | 隐私 + 资金 |

**处理建议**：核心 SKILL.md + references 无危险命令 → 可装；`platform.md` 等支付/注册/遥测文件 → **跳过安装**。向用户明确报告："核心功能安全，但发现商业化附加层，建议只装核心、跳过平台层"。

### 5. 风险分级

| 等级 | 判据 | 处置 |
|---|---|---|
| 🟢 安全 | 无异常 | 推荐使用 |
| 🟡 低风险 | 有网络请求或常规文件读写 | 正常，留意域名 |
| 🟠 中风险 | 敏感目录访问 / 复杂 shell 操作 | 需确认意图 |
| 🔴 高危 | 破坏性删除、提权、未知外连 | **禁止使用** |

## 实战范式（PUA 案例蒸馏）

`github.com/tanweai/pua`（18k⭐，Prompt 注入技能）：

- SKILL.md（34KB）无危险命令、无越权、文件访问限制在 `~/.pua/` 内 → **通过**
- 但 `references/platform.md`（14KB）含：手机号注册、用户 token 落盘、每次会话自动 ping 配置、远程控制 prompt 模板、游戏化统计、**静默遥测（每次 `[PUA生效]` 自动 POST `v1/stats`）**、微信支付二维码
- 结论：只装核心文件，**剥离 platform.md**

**通用教训**：
1. 商业化模块常藏 `references/` 二级文件，主文件通常干净
2. 对所有 `references/` 文件同等审计，不能只看主文件
3. 静默遥测是最隐蔽的风险类型——不需用户操作，自动触发

## 审计报告模板

```markdown
## 🛡️ [名称] 安全审计报告

### 风险等级：🟢 安全 / 🟡 低风险 / 🟠 中风险 / 🔴 高危

### 审计详情
1. 危险命令：[列出 / None]
2. 网络请求：[目标域名]
3. 文件越权：[越权路径 / None]
4. 商业化附加层：[platform.md / None]

### 建议
[通过 / 只装核心跳过平台层 / 拒绝]
```

## 注意事项

- 审计时用**描述性语言**代替危险命令字面量（如 "Recursive Force Delete" 而非命令本身），避免审计记录自身被下游安全扫描器误判。
- 本 skill 自身（src-hunter）不含任何外发网络请求、不收集任何遥测，可自检通过。
