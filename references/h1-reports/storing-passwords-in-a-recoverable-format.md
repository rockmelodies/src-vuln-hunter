# Storing Passwords in a Recoverable Format

_2 reports — High/Critical, disclosed_

- **External storage app saves password for all users in the database** — `Nextcloud` · `High` [↗](https://hackerone.com/reports/867164)
  - `CVE-2020-8296` External storage (files_external) app save passwords of all users to database table "oc_credentials" even when "Log-in credentials, save in database" option is not used.
- **Password Cracking - Weak Password Used to Secure ████ Containing a Plaintext Password** — `U.S. Dept Of Defense` · `High` [↗](https://hackerone.com/reports/985133)
  - I was able to crack the password to the ████████ located at ██████, as the pdf was protected with a weak password contained in a common word list.
